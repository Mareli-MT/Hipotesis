# Hipotesis

## Hipótesis del proyecto integrador

Si se implementa el proyecto integrador, basado en sensores y tecnología ESP32 conectados a una aplicación móvil, entonces será posible mejorar el control de los residuos reciclables mediante la supervisión de los contenedores en tiempo real, facilitando la detección de su capacidad y la planificación de la recolección. Como resultado, se espera disminuir el desperdicio de recursos y contribuir a mantener espacios más limpios y ordenados.
